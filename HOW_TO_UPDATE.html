🌸 Quick Guide

How to Edit Prices & Images for JMS Fresh Flowers

All your products, prices, and photos are organized in one single file called products.js.

1️⃣ Open products.js in Notepad

Right-click the file products.js in this folder and choose "Open with" → "Notepad" (or VS Code / any text editor).

2️⃣ Changing the Price (ரூபாய் விலை மாற்ற)

Look for the lines marked with 🟡 [EDIT PRICE HERE]. Change the number to whatever price you want:

{
  id: "f1",
  name: "Madurai Gundu Malli (குண்டு மல்லி)",
  category: "flowers",
  unit: "1 Mozham / 100g",

  // 🟡 👉👉👉 [EDIT PRICE HERE] 👈👈👈
  price: 150,    <--- CHANGE 150 TO YOUR PRICE (e.g. 180, 200)

  // 🟢 👉👉👉 [EDIT IMAGE HERE] 👈👈👈
  image: "images/malli poo.jpg",
}
3️⃣ Adding Your Own Photos (புகைப்படம் மாற்ற)

Save your flower photo inside the images/ folder.

Then in products.js, look for the line marked with 🟢 [EDIT IMAGE HERE] and put your photo's name:

  // 🟢 👉👉👉 [EDIT IMAGE HERE] 👈👈👈
  image: "images/gundu-malli.jpg",   <--- PUT YOUR FILE NAME HERE

(You can also paste a direct image URL from Google or any website!)
